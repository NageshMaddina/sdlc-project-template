# CHG-000 — Bootstrap the stack

Status: Draft
Type: Infrastructure
Affects: ADR-0001

## Why
The template has process, rules and pipelines but no application. Every gate in CI needs real scripts to run.

## What changes
Scaffold the stack in ADR-0001 so the empty app builds, deploys and is observable — see `.claude/skills/bootstrap/SKILL.md` for the target end state.

## Acceptance criteria
- **AC-000.1** — Given a fresh clone with `.env` from `.env.example`, when the developer runs `pnpm install && pnpm dev`, then `GET /api/healthz` returns `200 {"status":"ok"}`.
- **AC-000.2** — Given the database is unreachable, when `GET /api/readyz` is called, then it returns `503` with `{"status":"degraded","checks":{"db":"fail"}}` and logs `health.ready_failed`.
- **AC-000.3** — Given any request, when it is handled, then exactly one JSON log line with `requestId` and `traceId` is written and no secret env values appear in logs.
- **AC-000.4** — Given a pull request, when CI runs, then every gate job (static, unit, traceability, security, build, e2e, visual) executes and passes on the scaffold. (verified by: CI run on the CHG-000 pull request)
- **AC-000.5** — Given the home page, when rendered, then its visual test matches the approved baseline and it has no axe accessibility violations.

## Risk and rollback
Low; nothing is in production yet. Rollback = delete the branch.
