# Prompt library

The prompts you type to drive each SDLC phase. They are short on purpose: the rules,
skills and hooks carry the detail, so the same short prompt produces the same disciplined
behaviour every time. Copy, fill the brackets, paste into Claude Code.

Keep this folder versioned. When a prompt produces a bad result, fix the prompt (or the
rule/skill behind it) and commit the change with a CHG ID, so the history shows how you
directed the AI.

| When | File |
|---|---|
| Starting a new project from this template | `00-new-project.md` |
| Each phase, in order (01 requirement … 08 observe) | `phases.md` |
| Bugs, change requests, reviews, incidents, a session that drifted (09–13) | `situations.md` |
